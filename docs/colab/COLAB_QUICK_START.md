## 🆘 Troubleshooting

### Issue: Package installation gagal
**Fix**: Run cell lagi atau restart runtime

### Issue: Upload timeout
**Fix**: Gunakan dataset yang lebih kecil

### Issue: Out of memory
**Fix**: Restart runtime atau gunakan sample dataset
